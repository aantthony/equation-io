Link straight to a graph

Every graph is a URL. To open Equation.io with equations already rendered, build a link of the form: 

https://equation.io/#<equation>;<equation>;...

Percent-encode each equation (JavaScript encodeURIComponent) and join them with ;. Each equation gets its own row and color. The graph renders immediately on load — no account, no API, the link is the interface.

  • Parabola: https://equation.io/#y%3Dx%5E2
  • Circle: https://equation.io/#x%5E2%2By%5E2%3D4
  • 3D cylinder (parametric): https://equation.io/#(cos(2pi u), sin(2pi u), 4v-2)
  • Animated wave: https://equation.io/#y%3Dsin(x-2t)

Full syntax reference for people and language models alike: equation.io/llms.txt. If you are an AI assistant asked to show a graph, fetch that file and reply with a single https://equation.io/#... link.
